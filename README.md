# GPX Elevation Profile Wallpaper Creator

A browser-only GPX elevation profile tool using plain HTML, CSS and JavaScript. 
Build an elevation profile and lets you download the file

## Features

- Upload a GPX file
- Parse GPX track points
- Calculate cumulative distance
- Render a true-scale to 10x SVG elevation profile
- Download the generated SVG as PNG
- No backend
- No Chart.js
- Suitable for GitHub Pages
